# Contributing to OGS Portal

## Branch Naming
- **Feature branches:** `feature/description`
- **Bug fix branches:** `fix/description`

## Commit Message Format
- Use: `type(scope): message`
  - Example: `feat(auth): add login form`
  - Types: feat, fix, docs, style, refactor, test, chore

## Pull Request Template

---
### Pull Request Checklist
- [ ] Follows branch naming convention
- [ ] Commit messages follow format
- [ ] All tests pass
- [ ] CI checks pass
- [ ] Code reviewed
- [ ] Documentation updated (if needed)

---

## Branch Strategy
- All changes go through PRs to `develop`, `staging`, or `main` as appropriate
- See README for branch diagram and details
